# Sola / 4Seas 活动中文说明

根据2026-10-26读取的公开列表整理。Sola是活动平台，此处主要为4Seas Community活动，非CO-HUB已经开办的活动。除注明详情已读的三项，其余为标题释义，不表示核实全部流程。

| Vibecoding for Women | 面向女性的AI编程工作坊：用Claude Code等工具做网站或小应用，说明电脑与账号准备；详情已读。 |
