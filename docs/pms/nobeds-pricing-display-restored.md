# NOBEDS 收费展示参考与 JOVIAN 需求

核查日期：2026-10-15。只读查看[官网首页](https://nobeds.com/)及[价格页](https://nobeds.com/prices/)，展开相关费用FAQ；未注册、订阅或付款。用户要求先研究展示，具体收费标准下次讨论。本文件是需求记录，不是已批准的产品定价或实施设计。

## 可借鉴的展示方式

价格页把免费、专业、开发者三类方案并列，以大号月价、适用对象、功能差异和行动按钮帮助选择，并突出一个推荐项；下方配费用FAQ。页面展示的参考价分别为€0、€15、€99/月，属于NOBEDS当日页面内容，不是JOVIAN报价。方案差异涉及容量、渠道数量、同步频率、支持方式及开发集成。[来源：NOBEDS价格页](https://nobeds.com/prices/)

页面还设节省费用计算器和竞品对比，但其竞品价格与节省金额未独立验证，不作为JOVIAN定价依据。FAQ将平台零佣金与支付网关处理费分开。页面同时存在免费容量“10间房”和“1–3个单元”两种口径；付费容量中“酒店、房源、无限房间”的表达也需要澄清。JOVIAN应借鉴清晰对照结构，避免容量口径和费用边界含糊。[来源：NOBEDS价格页](https://nobeds.com/prices/)

## JOVIAN 公开收费页面要求

访客无需登录即可查看，桌面与手机均易读；首屏看到方案名称、适用对象、价格及币种、计费周期、主要额度、核心差异和下一步入口。支持中文、英文、马来文，保留扩展语言能力。

| 展示区域 | 应说明什么 | 当前状态 |
|---|---|---|
| 方案卡片 | 方案名称、适合谁、价格/周期、主要额度、行动入口 | 方案数量、命名、金额及是否提供免费版均待讨论 |
| 计费单位 | 按门店、房间、床位、整套或其他单位；包含额度及超额规则 | 未决定；须适配房间/整套/床位混合销售 |
| 功能对照 | 房态订单、多门店、员工权限、清洁维修、财务、网页、自助入住、多OTA消息、支持服务 | 区分包含、额外购买、未提供、规划中 |
| 费用明细 | 软件订阅、渠道服务、支付手续费、短信/通信、门锁服务及硬件、设置培训等 | 不假定全部收费，也不假定全部免费；按最终合作条款披露 |
| 支持服务 | 帮助中心、客服渠道、服务时段、响应承诺及培训 | 按实际人员能力定义，不承诺未经确认的全天候服务 |
| 条款与FAQ | 税费、月付/年付、试用、续费、升级降级、取消、退款、数据导出 | 所有商业规则待确认后再写正式文案 |
| 选择入口 | 联系咨询/申请演示/开始使用等 | 入口必须与实际交付能力一致，不先接入付款 |

## 关键展示原则

1. 软件订阅、OTA服务商费用、OTA自身佣金、支付网关费分别解释；“无平台佣金”不能让访客误以为所有第三方费用均为零。
2. 同一页、官网首页和后台订阅页使用同一套餐配置，防止额度与价格不一致。
3. 混合库存须定义计费规则：例如同一物理房间既整房出售又按床出售，是否重复计费必须明确；真实10间房＋30床位布局仍待确认，不能先当作40个独立计费单元。
4. 按门店/账号/员工数量的权限与额度分开说明；统一后台支持多门店不等于所有方案无限门店。
5. 未上线的OTA消息、支付、门锁、自助入住、完整财务不能标为已包含可用。当前v0.3仍是单浏览器本地原型。
6. 可先设计静态方案展示和对照，价格用明确的“待确认”状态供内部评审；未经正式定价不发布虚构金额、折扣、试用或免费承诺。
7. 费用估算器和竞品比较可留待后续；只有计费模型确定且有证据后才展示，不先加入看似精确的节省金额。

## 后续定价讨论所需输入

确认目标客户及上线范围、计费单位、套餐功能边界、渠道服务商成本、消息及支付费用、门锁硬件与服务成本、客服投入、税费币种，以及试用/续费/取消政策。此次只完成参考研究与需求记录，不开展接口选型或商业价格决策。
