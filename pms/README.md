# JOVIAN PMS 0.4 — 共享后端开发版

一套系统支持CO-HUB青旅和JOVIAN酒店式公寓。本版新增服务端数据库、账号会话、角色和门店授权、版本冲突处理、幂等命令和审计。仍是开发环境，不代表完整SmartOrder功能已对齐，不用于营业，不连接OTA/支付/TTHotel，不部署现有官网。

## 启动共享开发模式

需要 **Node.js 24或更新版本**，无第三方npm依赖。使用内置node:sqlite，可能显示实验性API提示。无需Python或另装数据库。

在pms目录执行：

```sh
npm run setup
npm start
```

setup输入：账号（3–64位字母/数字/点/下划线/短横线）、密码（至少12字符，输入隐藏）、角色、门店。门店可填`TEST-KL,TEST-PG`，也可仅填一个；留空为两家测试门店。没有默认账号或通用密码，不要使用真实系统密码。

角色：`admin`管理员、`operations`运营、`finance`财务（仅收付命令）、`viewer`只读。管理员和运营目前前台操作权限相同，账号创建通过本机setup完成；尚未做后台用户管理。角色只影响已授权门店；管理员不会隐式获得所有店。现场专用清洁角色和敏感财务字段隔离尚未实现，不要给现场团队分配完整运营账号。

重复运行setup可创建另一账号，不会重置订单或覆盖同名账号。密码重置、用户停用及角色变更界面尚未交付。

Windows：安装Node.js 24+后双击`START-WINDOWS.bat`。首次会提示建账号；如浏览器先打开但服务未就绪，刷新一次。可双击`SETUP-ACCOUNT-WINDOWS.bat`添加另一个账号。Windows脚本已检查文本，但未在真实Windows执行。

服务器默认仅监听本机：**http://127.0.0.1:8010/web/**。在同一台电脑使用两个不同浏览器/独立配置分别登录，测试共享数据。另一台电脑暂时不能连接；本次未开放局域网或公网。不要把云端的127.0.0.1发给同事当测试链接。

## 保存与协作

- 数据库默认`.data/jovian.sqlite`，含账号哈希、订单、房态、流水、会话和审计；被.gitignore排除，不能打包或提交。重启保留数据。
- `PMS_DB`可指定独立测试数据库；`PMS_PORT`可改端口。setup和start必须使用同一个PMS_DB。
- 服务端是共享模式的唯一写入方，不接受浏览器算好的库存。所有修改都在BEGIN IMMEDIATE事务中执行，再提交资源逐夜占用约束及审计。
- 门店revision变化后旧页面提交返回409；界面刷新并提示核对重试。当前不实时推送，另一账号点击顶部刷新按钮读取最新数据。
- 收款请求使用幂等键；当前页面遇到短暂传输失败可原内容重试。若结果不明，不要刷新后重新造一笔收款，要先核对流水；完整离线队列和跨重载恢复尚未实现。
- 账号会话8小时，HttpOnly/SameSite cookie、请求来源及CSRF校验；仅适合本机HTTP开发。生产必须有HTTPS、Secure cookie、部署与备份方案及进一步安全验证。
- 初始数据仅有合成双店资源，没有真实客人。不会导入旧版localStorage测试订单。资源布局仍不可在界面配置。
