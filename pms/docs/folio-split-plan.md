# Split folios

Allocate the existing stay charge and receipts in minor units without posting new revenue. Keep deposits at stay level. Route subsequent room payments to a selected open bill. Derive the original stay closure from all bills. Record a reversal referencing the original settlement and keep all receipt rows. Split reversal requires every bill open. Legacy stays keep their existing workflow. Register server, finance role and UI permission entries, then exercise reducer, shared HTTP and DOM before deployment.
