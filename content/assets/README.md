# content/assets/ 素材管理说明

COHUB 的**每条内容都必须配图或配视频**，没有素材的内容不得进入「已批准待排期」。

## 目录结构

```
content/assets/
├── images/         # 成品配图（压缩后，可直接用于发布）
│   └── 2026-11/    # 按年月分目录
├── videos/         # 短视频原文件（如需进仓，压缩后再放）
├── originals/      # 原始大图 / 未经压缩的实拍照片（尽量外链，不进仓）
└── _SOURCES.md     # 素材来源与授权登记（实拍照片必须登记）
```

> 仓库只跟踪**轻量成品**；原始大文件建议放网盘/云盘并在内容文件里记外链。

## 命名规范

`YYYYMMDD-平台-简述-序号.扩展名`，例如：
`20261101-ig-digital-nomad-morning-01.jpg`

与对应文案文件（`content/published/20261101-ig-digital-nomad-morning.md`）用同一前缀，便于对应。

## 平台尺寸

| 平台 | 推荐尺寸 | 比例 |
|------|----------|------|
| Instagram | 1080×1080 或 1080×1350 | 1:1 / 4:5 |
| Facebook | 1200×630 | 1.91:1 |
| TikTok | 1080×1920 | 9:16 |

## 素材来源标注

每条素材必须标明来源，写在对应内容文件的「素材」区块：

- **AI 生成**：写明生成日期与提示词要点；生成图不得出现真人肖像、不得伪造品牌 Logo 或虚假场景
- **实拍照片**：拍摄者、拍摄日期、地点；**画面中出现可识别的客人/员工时，须先取得本人同意**，否则不得用于发布
- **素材库 / 网盘**：写明来源平台与外链

## 视觉调性

与 [`cohub/brand-and-facts.md`](../../cohub/brand-and-facts.md) 一致：温暖、放松、开放、有活力、社区感。
呈现工作场景时突出 Wi-Fi 与电源插座等要素，但**只使用业主已确认的具体信息**，不虚构空间细节。

## 禁止事项

- 不把账号密码、令牌、Cookie 写入素材文件名或说明
- 不使用来源不明、未获授权的图片（含网络下载图、他人作品）
- 不在图片上叠加未经确认的价格、时间、活动信息
